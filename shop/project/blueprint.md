# Shopping Center Application Blueprint

## Overview

A modern, responsive e-commerce application built with the latest features of Angular. This application provides a seamless shopping experience with a clean and intuitive user interface.

## Style, Design, and Features

### Color Palette

- **Primary Color:** `#007bff`
- **Secondary Color:** `#0056b3`
- **Text Color (Light):** `#343a40`
- **Text Color (Dark):** `#f8f9fa`
- **Header Background (Light):** `#f8f9fa`
- **Header Background (Dark):** `#343a40`
- **Footer Background (Light):** `#f8f9fa`
- **Footer Background (Dark):** `#343a40`

### Components

- **`AppComponent`**: The root component of the application.
- **`HeaderComponent`**: A responsive header with navigation and a dark/light mode toggle.
- **`FooterComponent`**: A simple footer with copyright information.
- **`HomeComponent`**: The landing page with a hero section.
- **`ShopComponent`**: A placeholder for the shop page.
- **`ContactComponent`**: A contact page with a form and a map.

### Features

- **Dark/Light Mode:** A theme switcher in the header to toggle between dark and light modes.
- **Responsive Design:** The layout adapts to different screen sizes.
- **Routing:** Navigation between the home, shop, and contact pages.
